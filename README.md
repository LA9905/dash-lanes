# Dash Lanes

Juego endless runner móvil.

## Características
- 3 carriles para esquivar obstáculos
- Sistema de niveles con puntuación mínima
- Disparos limitados en niveles avanzados
- Peatones, monedas y explosiones
- Récord guardado y selección de nivel
- Controles táctiles y de teclado

## Stack
- Phaser 3
- TypeScript
- Vite
- Capacitor (Android)

## Cómo jugar
- Izquierda / Derecha → cambiar carril
- Centro → saltar
- Arriba → disparar (si está disponible)
